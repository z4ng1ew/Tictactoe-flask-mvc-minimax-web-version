| `curl: (7) Failed to connect` | Сервер не запущен | Запусти `python main.py` в другом терминале |
| `500 Internal Server Error` | Ошибка в коде контроллера | Посмотри трейсбек в окне сервера, исправь `controller.py` |
| `400 Bad Request` без описания | Неверный формат JSON | Проверь кавычки и запятые в `-d '...'` |
| Ответ не содержит `2` | Компьютер не сделал ход | Проверь, что в матрице есть свободные клетки (`0`) |
| Скрипт `play.sh` падает | Ошибка в парсинге | Запусти с `bash -x play.sh` для отладки |
